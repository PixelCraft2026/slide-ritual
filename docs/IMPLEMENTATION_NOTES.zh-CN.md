# 暗室 · 私人幻灯放映室

双击 **`darkroom.html`** 即可离线使用。单文件约 2.9 MB，内嵌三维引擎、照片、声音、样式和代码，不需要安装依赖或联网。点击右侧「文件夹」，选好文件夹后自动开机并放映。包含子文件夹，按相对路径和文件名自然排序（2 在 10 前），忽略非照片文件；更换文件夹会替换本次片匣。设置中也可以选择单张照片追加。

开发版可运行 `node server.mjs`，或在 PowerShell 执行 `./start.ps1`，然后打开 <http://localhost:8790>。服务只监听本机；导入的照片不上传，也不写回原文件。刷新页面会结束本次片匣会话。

## 2.7 默认观感与折叠设置

- 机身回光来自投影墙一侧，将原来瞄准地面的高位光校正为瞄准上盖的较低仰角回光，取消观众侧定向补光和随电源增强的环境光。墙面回光随照片遮光归零，保留低强度、独立的房间环境光。上盖参与回光遮挡，避免后沿被穿透机身的光照亮。静态机壳使用共享几何的 1024×1024 缓存阴影，仅在俯仰改变时重建；移动片框、片匣和输片臂不加入此静态遮挡场景，其槽内漏光阴影仍实时更新。墙面使用单一主方向近似宽幅回光，不是完整面积光源或光线追踪。
- 移除靠墙前沿额外隆起的反光冠部与重叠面，恢复单层四分之一圆弧；按轮廓绕向生成向外法线。亮边由曲面材质、光源和观察角度共同产生。
- 按后续视觉反馈，在机箱与灯室的靠墙前沿各增加一道窄反光细条，宽度按反馈缩窄一半，保留推片臂左端固定外壳修改前的材质参数。细条沿完整前沿及两端圆角贴合，延续到原有圆弧外缘，与机箱表面齐平，不产生额外凸起或投射阴影；接受场景回光及遮挡，不自发光。左端固定外壳和相连杆件改用独立黑塑料材质，反射参数与后侧黑色遥控器一致；前沿黑色小片也采用该遥控器材质。关闭靠观众一侧两端的局部镜面高光，保留圆弧结构和漫反射；其他机壳材质不共用此修改。
- 前景虚焦默认 4.0；泛光默认 30%，范围 0–100%；顶盖反射默认 70%。移除界面上的「调试」字样。
- 墙面散射对 Canvas 模糊进行实际像素检测，避免 iPad Safari 忽略 `ctx.filter` 后出现放大照片重影。模糊不生效时，以最长边 512 像素的缓冲区预计算三次可分离盒式模糊，使用预乘透明度避免黑边；动画期间只缩放和复用缓存，不执行逐帧模糊或像素读取。支持原生 Canvas 模糊的浏览器继续使用原路径。
- 切换照片后只横向滚动缩略图栏，保持设置面板的纵向阅读位置，避免 `scrollIntoView()` 连带滚动祖先。
- 首次开机立即点灯，首张解码和画面准备与灯泡预热及五秒白场并行，音频下载不阻塞开机。页面提前请求首张示例照片、播放音频和 JavaScript 模块，同一张照片正在加载时复用请求；两路 GPU 初始化并行。离线版移除网络预加载标签，资源继续内嵌。
- 自动放映在开场期间提前下载下一张照片，当前照片稳定停留时完成下一张的缩图、墙面散射、原生 HDR 曝光和 GPU 资源准备，切换时复用准备结果，避免在四秒停留结束后才等待网络与解码。只预备相邻下一张，沿用有界缓存；视口、显示模式及光学设置变化时重新准备，暂停、关机或换片匣后丢弃过期任务。
- 过片音效更新为 2026 年 10 月 7 日最后提供的录音，截取 0.36–2.15 秒中的单次机械动作，分别以保持音高的时间伸缩制作普通过片 1.5 秒和开场 1.85 秒版本，首尾短淡化。运行时均以 `playbackRate=1` 播放，开场不再降调。移除 2.2 kHz 低通和 1.3 kHz 高频搁架滤波，保留录音的高频细节与瞬态，只调整整体增益。机械音量默认 55% 不变，按实际浏览器播放链路重新校准两种时长的响度，使其接近移除滤波前。在线与离线播放使用 MP3 副本（普通过片约 24 KB，开场约 30 KB，风扇约 95 KB），公开仓库只保留当前三份 MP3 播放文件；音频迟到时只补充仍需要的风扇声，不重放过去的过片声。
- 页面从后台返回时检测音频恢复结果及音频时钟，限制挂起的 `resume()` 等待时间；恢复失败后在下一次点击或按键中重建音频连接。声音开关即时更新，重新开启会在该点击中重建连接。保留声音开关、机械音量、风扇音量和开机状态，复用音频缓存，并清理旧声源，避免重叠风扇声或重放后台过片声。
- 墙面散射、空气散射、泛光强度、顶盖反射、机箱光源统一放入默认收起的「光照设置」。
- 「幻灯机位置」保留垂直滑块，默认向下 5% 画面高度；取消水平移动，新增俯仰角度 ±12°，默认 0°。俯仰直接旋转三维模型，机械动作、光源和光锥起点随之变化；位置复位恢复下移 5%、俯仰 0°。
- 新增「幻灯片位置」，只调节上下位置，默认向下 3% 画面高度。照片、开场八边形、裁切光孔、墙面漫反射和空气光锥的照片端共用同一中心；调整照片位置不会移动幻灯机。幻灯片位置复位恢复下移 3%。

## 2.5 光效调整（历史）

- 五个格窗的底色本身持续发光，三角形与椭圆形亮区在纹理内模糊后平滑叠入，不再叠加独立的纯白块。发光保留暖黄色，窗口之间仍有暗色筋条。
- 泛光同时来自格窗、顶部横缝和右侧漏光，增加近、中、远多层柔光扩散；直接发光的位置减少重复叠亮，保留窗口层次。黑场中能看到更宽的暖色光晕。
- 右侧设置新增「泛光强度」滑块，范围 0–300%，默认 100%，0 关闭泛光。强度独立于光源本体亮度与统一曝光倍率，可在放映和换片过程中实时调整。
- 将过片曝光统一为同一条曲线：稳定放映为 1.00，黑场与照片进场为 1.34，落座后平滑回到 1.00。照片、格窗、横缝、侧漏光以及泛光共用相同的线性曝光倍率；右侧机械运动的遮挡仍由几何与阴影产生。移除了此前每个光源各自的提亮系数和透明度跳变。显示端的伽马、色调映射、遮挡及背景叠加会影响截图像素比值，1.34 指渲染前的线性倍率。
- 两条圆弧边沿使用与顶盖相同的颜色、粗糙度、金属度和场景照明，移除独立照亮边条的光源与第二次渲染。反光由曲面朝向产生，只保留微弱的边沿层次。
- 修复左侧墙面的直线接缝：原淡雾渐变在自己的局部矩形边界仍未归零，被硬裁切；现改为全屏、连续衰减到透明的椭圆渐变。

## 放映体验

- 页面本身就是完整暗室。墙面投影位于上方，幻灯机贴近屏幕下沿，以站在机器后方的视角观看；前景保留明显虚焦，屏幕没有相框或产品页布局。
- 2.2 将镜头光轴与照片水平中心对齐，手机上也保持居中。横幅、竖幅使用相同的光学范围：3:2 横幅的宽度、2:3 竖幅的高度与八边形空片门边长相同。方形及其他比例按八边形边界完整容纳。
- 依据 `reference/` 中六张 P150 照片重新建立 Three.js 三维几何：银灰上盖、黑色底壳、独立灯室盖、五个有深度的散热槽、后部开关、对焦片、镜头、输片臂、直式片匣和独立幻灯片。机身采用倒角、粗糙表面、暖色漏光与投影反射照明；这是照片参考重建，不是扫描模型。
- 依据新增 `back.JPG` 与 `s-l960 (1).webp` 补齐背部控制板、绿色按键、滚花旋钮、凹圆位、手指凹口、后方电源开关、灯室盖与对焦片层次；重建右侧挡墙、顶沿、32 个带斜肩和底部缺口的隔槽，并校正片匣长度。没有使用发光外壳或盖板上方的大光晕；左侧光源位于五个真实开孔内部，输片臂下方另有细长漏光缝。
- 墙面散射从当前照片的空间颜色生成多尺度漫射，亮暗与过片遮光同步。投影关闭时散热孔继续发光。前景光晕、墙面细纹、暗角与独立可调的前景虚焦共同模拟参考的拍摄观感。漫反射与景深为实时近似，未进行光线追踪。
- 光路新增轻微空气散射与稀疏浮尘：漂浮颗粒只在光束范围内显现，随片门遮光熄暗；光路跟随镜头位置、画幅与过片中的窄缝。减少动态效果时浮尘静止，切到后台停止动画。空气单独绘制在照片后方，保留 HDR 照片的原始显示表面。
- 「空气散射」滑块可在 0–500% 之间实时调整，默认 140%；0 同时关闭这一路光束和浮尘，强度增加实际改变散射像素，不在 100% 处饱和。墙面散射仍可独立调整。
- 右侧进片口有独立暖色漏光，照亮邻近几张片框的顶边和侧面；片框具有开孔、半透明胶片，输片臂与片框参与局部阴影。墙面全黑时漏光仍亮，抽片、推片时遮挡和光量改变。
- 过片保持 1500 ms 总时长：旧片 200 ms 连续向左移出，随后 767 ms 全暗；新片 200 ms 从左侧连续移入，之后 333 ms 恢复亮度。照片与光孔分别定位，仅固定八边形光孔裁切照片，不再用移动的右侧遮罩代替平移；竖图按光孔与照片的实际宽度计算完整行程。片匣推进与输片臂分开运动，连续按键不会叠加过片，途中关机可立即中止。
- 运动模糊随平移速度变化，采用半帧曝光的近似，半径最多 8 CSS 像素，启停时归零。SDR 与可重建的 Adobe gain map HDR 使用显示尺寸的浮点纹理和 5 次横向 GPU 采样；HDR 复用曝光预览画布，退场倍率为 1，入场采用所设曝光挡位，落座后回到未经滤镜处理的原生图像。照片平移由浏览器合成器按显示刷新率执行，光照与 GPU 效果最多更新 60 次/秒。照片解码、gain map 重建、缩图、纹理上传和首次合成预热均在动画计时前完成；运动期间不读回像素、不重算 gain map、不配置新的画布。
- 外部机构按照「旧片向右抽出归槽 → 片匣前移一格 → 新片向左推入」运行：0–310 ms 抽片，310–390 ms 释放，390–610 ms 进匣，610–740 ms 对位，740–1167 ms 推入，余下时间落座。旧片与新片为两个独立对象，反向放映只改变片匣推进方向。在全暗阶段回收首尾卡片，保留其余卡片的实际坐标，完成时不回退；这是视频与用户描述约束下的动作近似，并非测得的内部机构时序。
- 过片保留 `reference/声音参考` 中的机械录音，通过 2200 Hz 低通与 1300 Hz 起的高频搁架衰减柔化咔哒声；背景改为 8 秒周期、稳定的宽带风扇噪声，不使用含房间窸窣声的背景录音。音量与声音开关独立可调。后台标签页暂停声音和自动放映。
- 完整显示照片，不裁剪横幅或竖幅。画面大小、投影亮度、镜头对焦、前景虚焦、墙面散射、质感、停留时间和循环均可实时调整。
- `←` / `→` 过片，`空格` 自动放映 / 暂停，`P` 电源，`M` 声音，`F` 沉浸，`Esc` 退出。双击投影画面也能进入全屏沉浸。
- 所有操作集中在右侧悬浮栏；鼠标、键盘和触摸停止操作 3.2 秒后，控制栏和设置一起滑出屏幕边缘，光标隐藏。任意鼠标移动或按键唤回。支持手机布局和减少动态效果的系统偏好。

## SDR / HDR

支持 JPG、PNG、WebP、AVIF，以及 Radiance RGBE `.hdr` / `.rgbe`。其他原生图片格式取决于浏览器解码能力。HEIC、RAW、EXR、TIFF 请先转换。单张文件上限 64 MB；Radiance 解码上限 1677 万像素。预览按比例缩小至不超过 2560 像素长边 / 300 万像素，只缓存两张已解码照片，原文件不变。

默认根据 `(dynamic-range: high)` 与实际 WebGPU 扩展能力选择显示模式；切换显示环境时重新检测。HDR 输出使用 `rgba16float` 与 `toneMapping: extended`，在 Display P3 色域内呈现。解码、亮度调整、对焦采样、高光扩展都在线性光域进行，最终按声明的色空间编码。

SDR 照片仅在亮部扩展亮度，默认峰值为参考白的 2 倍，可调至 1–4 倍。低于线性亮度 0.58 的中间调不扩展；这属于观片效果，不能恢复 SDR 文件已经丢失的高光细节。亮度数值是相对信号，不能作为显示器的实际尼特值。

Radiance 文件从 RGBE 直接解码为浮点值。普通图片由浏览器色彩管理解码；浮点读取能保留 HDR 时，使用浮点投影管线。对于检测到 HDR 元数据、但浮点读取没有保留高光的照片，保留原始 `<img>` 路径，由浏览器处理增益图或 PQ / HLG。此时原生 HDR 照片在 HDR 模式下关闭可能压平高光的亮度 / 模糊 CSS 滤镜，保持原始呈现；机械遮光与暗室效果仍然有效。元数据标记不等于已证明显示器呈现了 HDR。

无法使用 WebGPU 时回退到 WebGL2 SDR；没有图形 API 时回退到浏览器原生图片与 CPU SDR 预览。HDR 照片在 SDR 显示中映射为 SDR，不将 SDR 显示器标为 HDR。

实现依据：[Chromium WebGPU HDR 文档](https://developer.chrome.com/blog/new-in-webgpu-129)、[WebGPU 扩展亮度说明](https://github.com/ccameron-chromium/webgpu-hdr/blob/main/EXPLAINER.md)、[Canvas 浮点颜色说明](https://github.com/w3c-cg/ColorWeb-CG/blob/main/canvas_float.md)。机身参考：[Leica P150 原厂宣传册](https://www.summilux.net/documents/LeicaP150.pdf)。
