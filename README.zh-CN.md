# Slide Ritual · 虚拟放映室

[English](README.md) · **简体中文**

一个以 **徕卡 Leica P150** 幻灯机为灵感的网页观片室。暖色灯光、机械过片与风扇低鸣，让照片在显示器上慢慢放映，重拾观看幻灯片的仪式感，并在兼容环境下支持 HDR。

**[进入在线观片室 →](https://pixelcraft2026.github.io/slide-ritual/)**

![Slide Ritual 使用界面：冰湖照片投映在墙上，前景为虚拟幻灯机](preview.JPG)

## 主要功能

- 三维幻灯机、灯泡预热、片匣运动与机械过片录音。
- 随照片变化的墙面光、投影光束、浮尘与可调对焦。
- 照片在固定八边形光孔内连续移动，配合轻微的 GPU 运动模糊。
- 文件夹导入、自动放映、全屏观看与自动隐藏的控制栏，适配桌面及移动端浏览器。
- 支持 HDR，包括 Radiance `.hdr` / `.rgbe`；兼容 SDR 显示。
- 照片只在浏览器本地处理，不会上传。
- 完整暗室视频导出：SDR MP4、1080P／4K、30／60 fps、横屏 16:9／竖屏 9:16，可包含机械声音与风扇声。

## 开始观看

打开[在线版](https://pixelcraft2026.github.io/slide-ritual/)，点击 **文件夹** 导入照片，或点击 **先看示例**。支持简体中文与英文，默认跟随系统语言，也可在设置中切换。

演示依次放映 **冰湖、鱼灯、天文台** 三张照片。

移动触控设备的前景虚焦默认 **2.0**，桌面端默认 **4.0**。移动浏览器若不支持文件夹选择，可在设置中点击 **也可以选择单张照片**。

**← / →** 切换照片，**空格** 播放或暂停，**F** 全屏，**M** 声音开关，**P** 电源开关。

JPEG、PNG、WebP、AVIF 的支持取决于浏览器解码能力。HDR 输出需要兼容的显示器、系统设置与浏览器；其他环境使用 SDR。

兼容 WebGPU HDR 的浏览器中，Adobe gain map JPEG 使用重建的 HDR 预览实现运动模糊与入场时短暂增亮，随后恢复原生 HDR 原图。可在 **光照设置 → HDR 入场曝光** 调节 0 至 +2 EV，默认 +1 EV。其他原生 HDR 格式保留浏览器显示路径。

## 导出视频

点击控制栏中的 **导出视频**，选择分辨率、帧率和方向后开始导出。视频从第一张开始，包含开机白场和全部过片，每张沿用当前停留时间，最后一张停留结束即停止，不循环。导出时暂停网页放映及声音，结束、取消或失败后恢复原照片与播放状态；原本手动暂停的放映保持暂停。

导出每帧绘制一次完整场景。照片沿已知运动轨迹做连续模糊，机械采用运动矢量和深度，避免少量整帧平均的分离残影；仍保留 30 fps 的 1/60 秒、60 fps 的 1/120 秒快门。静态层缓存与原生视频帧减少重复绘制和读回，速度取决于设备。组件仅点击时加载，约 **69 KB gzip**，低于 200 KB 预算。

**光照设置 → 环境 Gamma** 仅调节墙面、光照和投影机，范围 0.50–2.00；照片与控制界面保持原样，SDR 导出也沿用此隔离。默认 1.00 保留现有显示路径；调整后才分配环境合成表面，使用 float16 缓存、浮点 GPU 曲线与最终显示量化时的微弱中性抖动，减轻暗部色带。原生 HDR 照片始终在环境处理路径之外。

30 fps 模拟 1/60 秒曝光，60 fps 模拟 1/120 秒曝光，过片使用多次时间采样，在线性光域合成运动模糊。导出组件点击后才加载；不上传照片，不使用录屏，不加载大型 WASM 编码器。优先直接保存到文件；不支持直接保存的浏览器完成后提供下载链接，下载路径限制视频大小为 512 MiB。

导出需要兼容的 WebGL 2 浮点渲染和 WebCodecs H.264／AAC 编码器，建议新版桌面 Chrome／Edge。4K、60 fps 及竖屏的支持按实际设备检测；导出速度取决于设备，可以慢于实际播放。离线单文件内嵌导出代码，点击导出后才解析执行。

导出模块构建后约 69 KB gzip，低于 200 KB 压缩预算。网络版需要服务器开启 HTTP 压缩；未压缩的模块约 257 KB。

## 本地运行

下载仓库后，直接打开 `darkroom.html` 即可离线观片。安装 Node.js 后，也可以运行源码版：

```sh
npm start
```

然后访问 [localhost:8790](http://127.0.0.1:8790)，无需安装项目依赖。

## 开发

项目使用原生 HTML、CSS、JavaScript 与本地提供的 Three.js。执行 `npm test` 运行单元测试。构建导出组件时运行 `npm ci` 和 `npm run build:export`；完整生成离线版与 Pages 目录运行 `npm run build`。观看网页及本地服务器不需要安装项目依赖。

技术细节见[实现说明](docs/IMPLEMENTATION_NOTES.zh-CN.md)。
